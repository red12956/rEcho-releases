# rEcho

A native, pen-first study workspace for reading documents, writing and asking an assistant.

rEcho 是原生的手写学习工作区，支持阅读文档、画板批注和 AI 助手。

## Downloads / 下载

[Releases and release notes / 安装包与版本说明](https://github.com/red12956/rEcho-releases/releases)

The first public package is being prepared. This repository contains release material only; the application source is maintained separately in a private repository.

首个公开安装包正在准备中。本仓库仅用于发布安装包和版本说明，不包含应用源码。

## Updates / 更新

Windows, Android and Linux builds use **Settings → About** to check, download and verify available updates, then open the system installer. Downloads begin only when you choose them. Availability depends on the packages published for your operating system and processor.

Windows、Android 和 Linux 构建可在**设置 → 关于**检查更新、下载并校验安装包，再交由系统安装。只有主动选择下载后才开始下载；可用版本取决于已发布的平台和架构。

Android updates require the same release signing identity. Windows publisher signing and Apple distribution will be documented when their distribution routes are ready.

Android 连续更新使用固定发布签名。Windows 可信发布签名与 Apple 分发方式确定后，将在此补充说明。

No desktop shortcuts are created by rEcho installers.

安装程序不创建桌面快捷方式。
